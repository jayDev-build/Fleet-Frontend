Implementation Notes for React
Colors (CSS Variables)
--navy: #0F2137
--blue: #1E5FAD
--amber: #F59E0B
--green: #16A34A
--red: #DC2626
--bg: #F0F4F8
Fonts (Google Fonts)
Rajdhani Bold 700 → All headings, numbers, amounts
DM Sans 400/500/600 → Body text, labels, buttons
Import both from Google Fonts in index.html
Mobile Rules
Min button height: 48px (touch targets)
Padding on screens: 16px horizontal
Card border-radius: 14px
Bottom nav: fixed, 64px height with safe area
No horizontal scroll ever
Money Formatting
₹1,50,000 → Indian number system
Use: amount.toLocaleString('en-IN')
Then prefix with ₹
Profit positive: green + "+" prefix
Profit negative: red
All amounts in Rajdhani Bold font
